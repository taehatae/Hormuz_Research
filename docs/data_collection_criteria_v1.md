# 호르무즈 뉴스 본문 수집·분류 기준안 v1

문서 상태: 검토 중인 1차 초안
작성일: 2026-10-31

## 1. 수집 목적과 범위

다양한 국가·지역의 영어 언론 보도를 확보하여, 향후 국가·지역별 보도 차이를 비교할 수 있는 자료를 구축한다.

현재 보유한 약 42만 건은 수집 후보 목록이다. 전체 수집이나 일정 비율 축소를 목표로 정하지 않는다. 연구 범위, 매체 다양성, 시기 분포와 본문 품질을 보면서 수집을 확대한다.

연구 결과의 적용 범위는 ‘각국 언론 전체’가 아니라 ‘선정된 무료 영어 매체의 보도’로 명시한다.

## 2. 유료 기사와 구독 전용 매체

| 확인 상태 | 처리 |
| --- | --- |
| 메타데이터에 유료 기사로 표시 | 수집 대상에서 제외 |
| 메타데이터에 비유료로 표시 | 수집 후보로 포함하고 실제 접근 시 확인 |
| 유료 여부 미상 | 별도 확인 대상으로 유지 |
| 실제 페이지에서 구독·결제가 있어야 본문을 읽을 수 있음 | 제외 |
| 일부 본문만 공개되고 나머지는 구독자 전용 | 불완전한 유료 기사로 제외 |
| 구독 홍보가 있지만 기사 전체는 공개 | 홍보 문구만으로 유료 기사라고 판정하지 않음 |
| 접속 오류·접근 차단 | 유료 여부와 구분하여 수집 불가 사유 기록 |

구독 전용 매체는 제외한다. 무료 기사와 유료 기사를 함께 제공하는 매체는 **무료 공개 기사에 한해 포함하는 것**을 기본안으로 한다.

## 3. 매체와 국가·지역 분류

비교 기준은 기사가 다루는 사건 발생국이 아니라 **보도한 언론사의 소속 국가·지역**으로 한다.

- 기존 `nc_country`는 초기 분류 자료로 사용하고 원래 값을 보존한다.
- 별도 열에 확인된 매체 국가, 지역, 판단 근거와 확인 상태를 기록한다.
- 도메인 주소나 기사 내용만으로 국가를 추정하지 않는다.
- 국제 매체·통신사·국제판은 운영 주체와 판본을 확인한다. 한 국가로 분류하기 어려우면 ‘국제·다국가’ 또는 ‘미확정’으로 남긴다.
- 지역은 국가 분류 후 일관된 대응표로 부여한다. 국가가 불명확하면 지역도 억지로 채우지 않는다.

초기에는 국가 정보를 보존하고, 지역 묶음은 향후 연구 질문에 맞게 조정할 수 있도록 한다.

## 4. 원보도 매체와 재게시 사이트

매체를 다음과 같이 구분한다.

- 자체 보도를 생산하는 언론사
- 통신사
- 여러 매체의 기사를 모으는 집계·재게시 사이트
- 기타·확인 필요

국가별 보도 비교를 위한 수집은 원보도 매체와 통신사를 우선한다.

재게시 기사는 원 출처와 재게시 매체를 구분한다. 집계 사이트의 국가를 원보도 매체의 국가로 대체하지 않는다. 원 출처가 불명확하면 국가별 비교 자료에 바로 포함하지 않고 별도 보관한다.

## 5. 영어·관련성·본문 품질 확인

- 영어 여부는 메타데이터로 먼저 선별하고 추출 본문의 실제 언어로 다시 확인한다.
- 제목이 영어여도 본문이 다른 언어이면 영어 분석 자료에서 제외한다.
- 기존 호르무즈 관련성 점수는 우선순위와 검토에 사용한다. 제목·미리보기에 키워드가 없다는 이유만으로 관련성 0인 기사를 일괄 삭제하지 않는다.
- 대상 기사와 다른 본문, 추천기사 혼입, 메뉴·광고·구독 안내, 실질적인 본문 누락을 점검한다.
- 추출 본문이 길다는 이유만으로 더 좋은 결과라고 선택하지 않는다.
- 여러 기사를 묶은 뉴스레터·불릿인은 별도 유형으로 표시한다.

## 6. 수집 확대 방식

먼저 국가·매체·기간별 후보 분포를 파악하고, 확인된 매체에서 시험 수집한다. 그 결과를 바탕으로 수집 범위를 확대한다.

고정된 10% 비율이나 최종 건수는 적용하지 않는다. 다음 항목을 확인하면서 다음 수집 대상을 정한다.

- 확보된 국가·지역과 매체의 다양성
- 특정 매체에 대한 집중 정도
- 국가 간 비교 가능한 기간의 확보 여부
- 무료 본문 확보율과 추출 품질
- 국가·매체별 제외 및 실패의 편중 여부

수집 성공률이 높다는 이유만으로 특정 국가나 매체만 계속 수집하지 않는다.

## 7. 보존과 기록

원본 파일과 기존 컬럼은 수정하지 않는다. 별도 파일에 다음 정보를 추가한다.

- 수집 대상 포함·제외·보류 상태와 사유
- 매체 유형, 확인된 국가·지역, 분류 근거
- 유료벽·접근 상태
- 추출기, 수집 시각, 저장 HTML 경로
- 실제 본문 언어와 품질 점검 결과
- 원 출처와 재게시·중복 관계
- 사람이 추가 확인해야 할 항목

같은 통신사 기사를 여러 국가의 매체가 재게시한 경우, 관계를 보존하여 독립적인 보도 관점으로 중복 계산하지 않도록 한다.
